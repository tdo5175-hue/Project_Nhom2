Đặc Tả Đề Bài & Thang Điểm Rubric

1. Mục Tiêu Đề Bài

Thiết kế Landing Page thương mại quảng bá thương hiệu cao cấp với bố cục mạch lạc, chuẩn responsive trên Mobile, kết hợp các tương tác JavaScript thuần chuẩn mực.

2. Yêu Cầu Kỹ Thuật Cốt Lõi

  • Tách File Độc Lập: Tách biệt 100% mã nguồn thành 3 file: Baitap4.html, css/baitap4.css, js/baitap4.js.
  • Sticky Header: Menu bám dính trên đỉnh khi cuộn trang, tự động điều chỉnh độ bóng nhẹ để phân tách nội dung.
  • Showroom Đổi Màu: Chọn màu sắc sản phẩm mượt mà với 3 phiên bản màu thực tế.
  • Tabs Thông Số: Phân chia tab thông số kỹ thuật rõ ràng với chuẩn ARIA đầy đủ.
  • Quản Lý Danh Sách (Chuẩn 4 tính năng .skill): Tích hợp đủ Tìm kiếm (Search), Lọc danh mục (Filter), Sắp xếp hai chiều (Sort), và Phân trang (Pagination 10, 20, 50, All).
