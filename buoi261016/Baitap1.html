📋 Nhật Ký Thực Hiện Dự Án & Prompt Engineering

Giai đoạn 1: Thiết kế cấu trúc (The Skeleton)

Prompt mẫu: "Bạn là một lập trình viên thiết kế UI, hãy xây dựng giao diện To-Do Dashboard responsive chuẩn CSS Grid (Sidebar bên trái 280px và Main Content bên phải) và Flexbox cho thanh nhập task. Có hỗ trợ chuyển đổi Sidebar trên Mobile."

✓ Đã hoàn thành: Semantic HTML5, CSS Grid 2 cột, Flexbox Form, CSS Variables cho Theme.

Giai đoạn 2: Lập trình chức năng tương tác (The Interactions)

Prompt mẫu: "Viết mã JavaScript thao tác DOM: Lấy dữ liệu ô Input tạo thẻ li mới. Xử lý click văn bản để gạch ngang chữ (toggle class completed). Click nút Xóa để phần tử biến mất với hiệu ứng Fade Out. Đồng hồ Header cập nhật mỗi giây bằng setInterval."

✓ Đã hoàn thành: Event delegation, DOM createElement, Class toggle, Smooth fade-out keyframes.

Giai đoạn 3: Tối ưu hóa dữ liệu & Bẫy logic (The Persistence)

Prompt mẫu: "Nâng cấp lưu trữ dữ liệu bằng LocalStorage (JSON.stringify & JSON.parse). Bắt bẫy logic: Nếu input trống thì alert cảnh báo và rung khung nhập. Thêm bộ lọc Trạng thái (All/Active/Completed) và Tìm kiếm Realtime."

✓ Đã hoàn thành: CRUD LocalStorage, Logic validation, Search & Filter đồng bộ, Lưu Dark Mode.

Yêu cầu mở rộng Điểm 9-10:

• Phân loại mức độ ưu tiên (High viền đỏ, Medium viền vàng cam, Low viền xanh lá).
• Nút chuyển đổi Dark/Light Mode lưu vĩnh viễn vào LocalStorage.
• Tìm kiếm tác vụ tức thời (Real-time Filter) không bị mất dấu khi reload.
