Cấu Trúc Website Kinh Điển: Holy Grail

Holy Grail Layout là thử thách bố cục chuẩn mực của thiết kế web hiện đại. Nhờ sức mạnh của CSS Grid (grid-template-areas), chúng ta có thể kiểm soát hoàn toàn 5 phân vùng mà không cần dùng float, định vị tuyệt đối hay các đoạn script phức tạp.

CSS Grid Core

grid-template-areas

Trực quan hóa bản đồ layout theo chuỗi ký tự ASCII: dễ đọc, dễ hình dung và tái cấu trúc chỉ trong một dòng lệnh.

Sticky Bottom Footer

Mobile-First Reordering
