Phân Tích & Chuẩn Hóa CSS Variables

Loại bỏ các giá trị cứng (hardcoded values) trùng lặp và chuyển hóa thành hệ thống Design Tokens với biến CSS var(--spacing-unit).

📊 Bảng Phân Tích Thuộc Tính Trùng Lặp & Biến Thay Thế

Thành phần / Thuộc tính Giá trị cứng ban đầu (Hardcoded) Biến CSS thay thế (var()) Mục đích UI/UX
Khoảng cách Grid & Padding gap: 20px; padding: 20px; var(--spacing-unit) Đồng bộ nhịp điệu không gian (8-pt/4-pt Spacing Rhythm)
Bo góc thẻ & icon border-radius: 10px; var(--radius-md) Đảm bảo sự nhất quán về độ cong viền toàn hệ thống
Màu nền thẻ (Card Background) background-color: #f1f5f9; var(--color-bg-card) Hỗ trợ đổi Theme (Light/Dark Mode) tức thì tại một nơi
Màu đường viền (Border) border: 1px solid #e2e8f0; var(--color-border-card) Kiểm soát độ tương phản viền theo tiêu chuẩn WCAG
Màu chữ & Tiêu đề color: #0f172a; / #64748b; var(--color-text-heading) Phân cấp thị giác (Visual Hierarchy) chuẩn mực
