Logic Đăng Nhập (Mô Phỏng Xác Thực)

📌
Yêu cầu đề bài: Tạo 2 biến username và password cố định. Viết cấu trúc if kiểm tra nếu người dùng nhập đúng cả 2 thì hiện "Đăng nhập thành công", nếu sai 1 trong 2 thì hiện "Thông tin không chính xác".
⚡ Khu vực thao tác trực tiếp
Tài khoản chuẩn: admin
Mật khẩu chuẩn: 123456
Test nhanh:
Đăng nhập thành công
• Trạng thái: Cả username và password đều khớp 100%.
• Chào mừng quản trị viên admin quay trở lại hệ thống!
>_ KẾT QUẢ THỰC THI (CONSOLE LOGGER)
Đăng nhập thành công với tài khoản: admin
🧠 Tư duy logic & Mã nguồn chi tiết
Baitap4.js 
// =========================================================
// BÀI 4: LOGIC ĐĂNG NHẬP (MÔ PHỎNG)
// =========================================================

// Bước 1: Khai báo 2 biến username và password cố định
const USERNAME_CHINH_XAC = "admin";
const PASSWORD_CHINH_XAC = "123456";

// Bước 2: Nhận dữ liệu đăng nhập từ người dùng qua prompt
let inputUser = prompt("Nhập tên đăng nhập (Mẫu: admin):");
let inputPass = prompt("Nhập mật khẩu (Mẫu: 123456):");

// Bước 3: Kiểm tra hủy bỏ
if (inputUser === null || inputPass === null) {
    console.log("Người dùng đã hủy thao tác đăng nhập.");
} else {
    // Bước 4: Cấu trúc if...else sử dụng toán tử logic VÀ (&&)
    // Cả username VÀ password đều phải khớp chính xác (dùng so sánh ===)
    if (inputUser === USERNAME_CHINH_XAC && inputPass === PASSWORD_CHINH_XAC) {
        // Trường hợp ĐÚNG CẢ 2:
        console.log("Đăng nhập thành công");
        alert("Đăng nhập thành công");
    } else {
        // Trường hợp SAI 1 TRONG 2 HOẶC SAI CẢ 2:
        // Lưu ý bảo mật: Báo chung 'Thông tin không chính xác' để tránh bị dò tài khoản
        console.warn("Thông tin không chính xác");
        alert("Thông tin không chính xác");
    }
}
