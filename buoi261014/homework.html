Bài tập 01

Chuyển Đổi Tiền Tệ Đơn Giản (USD → VND)

const TY_GIA = 25000 parseFloat() toLocaleString("vi-VN")
📌
Yêu cầu đề bài: Viết mã JS cho phép nhập số lượng USD và tính ra số tiền VND tương ứng (giả sử tỉ giá 25.000). Kết quả hiện ra console.
⚡ Khu vực trải nghiệm trực tiếp
Tỉ giá quy ước: 1 USD = 25.000 VNĐ
Chọn nhanh:
Bấm nút "Tính Thành Tiền" để xem kết quả.
🧠 Phân tích thuật toán & Code mẫu
1 Input: Nhập số tiền USD qua prompt() hoặc ô input, ép kiểu bằng parseFloat().
2 Validation: Kiểm tra isNaN() hoặc số âm (tiền tệ không âm).
3 Process: Áp dụng công thức VND = USD * 25000.
bai1_homework.js 
// Hằng số tỉ giá quy đổi cố định
const TY_GIA = 25000;

// Nhận giá trị USD và ép kiểu số
let inputUSD = prompt("Nhập số lượng USD:");
let usd = parseFloat(inputUSD);

// Kiểm tra tính hợp lệ
if (isNaN(usd) || usd < 0) {
    console.error("Số USD không hợp lệ!");
} else {
    let vnd = usd * TY_GIA;
    // In ra Console theo đề bài
    console.log(`${usd} USD = ${vnd.toLocaleString("vi-VN")} VND`);
}
Bài tập 02

Kiểm Tra Số Chẵn / Số Lẻ

n % 2 === 0 Number.isInteger() Số âm & Số 0
📌
Yêu cầu đề bài: Nhập một số bất kỳ từ bàn phím. Thông báo cho người dùng biết đó là số chẵn hay số lẻ.
⚡ Khu vực trải nghiệm trực tiếp
Toán học: Chẵn/lẻ chỉ áp dụng cho tập số nguyên (Z).
Thử ngay:
Bấm nút "Kiểm Tra" để xem kết quả.
🧠 Phân tích thuật toán & Code mẫu
1 Bản chất: Số chẵn là số chia hết cho 2 (phần dư = 0).
2 Bẫy số âm trong JS: Với số âm lẻ (như -3), toán tử -3 % 2 cho kết quả -1. Vì vậy dùng điều kiện n % 2 === 0 là an toàn tuyệt đối cho cả âm và dương.
bai2_homework.js 
let input = prompt("Nhập số nguyên:");
let n = Number(input);

// Kiểm tra số nguyên hợp lệ
if (isNaN(n) || !Number.isInteger(n)) {
    alert("Vui lòng nhập một số nguyên hợp lệ!");
} else if (n % 2 === 0) {
    console.log(`Số ${n} là SỐ CHẴN.`);
    alert(`Số ${n} là SỐ CHẴN.`);
} else {
    console.log(`Số ${n} là SỐ LẺ.`);
    alert(`Số ${n} là SỐ LẺ.`);
}
Bài tập 03

Tính Chỉ Số BMI Cơ Bản & Đánh Giá Thể Trạng

BMI = W / (H * H) toFixed(2) Thang đo WHO
📌
Yêu cầu đề bài: Nhập chiều cao (m) và cân nặng (kg). Tính BMI = cân nặng / (chiều cao * chiều cao) và in ra kết quả.
⚡ Khu vực trải nghiệm trực tiếp
Đơn vị mét (ví dụ: 1m70 nhập 1.70)
Đơn vị kilôgam (kg)
Mẫu thể trạng:
Bấm nút "Tính Chỉ Số BMI" để xem phân loại thể trạng.
🧠 Phân tích thuật toán & Code mẫu
1 Công thức: BMI = weight / (height * height).
2 Làm tròn: Dùng bmi.toFixed(2) lấy 2 chữ số sau dấu phẩy.
3 Phân loại (WHO): <18.5 (Gầy) | 18.5 - 24.9 (Chuẩn) | 25 - 29.9 (Thừa cân) | ≥30 (Béo phì).
bai3_homework.js 
let h = parseFloat(prompt("Nhập chiều cao (m):"));
let w = parseFloat(prompt("Nhập cân nặng (kg):"));

// Kiểm tra hợp lệ
if (h > 0 && w > 0) {
    let bmi = w / (h * h);
    console.log(`BMI = ${bmi.toFixed(2)}`);
    alert(`Chỉ số BMI của bạn là: ${bmi.toFixed(2)}`);
} else {
    alert("Chiều cao và cân nặng phải lớn hơn 0!");
}
Bài tập 04

Logic Đăng Nhập (Mô Phỏng Xác Thực)

user === CORRECT && pass === CORRECT Security Logic
📌
Yêu cầu đề bài: Tạo 2 biến username và password cố định. Viết cấu trúc if kiểm tra nếu người dùng nhập đúng cả 2 thì hiện "Đăng nhập thành công", nếu sai 1 trong 2 thì hiện "Thông tin không chính xác".
⚡ Khu vực trải nghiệm trực tiếp
Test case:
Bấm nút "Đăng Nhập" để kiểm tra xác thực.
🧠 Phân tích thuật toán & Code mẫu
1 Toán tử && (AND): Chỉ thỏa mãn khi CẢ HAI vế đều đúng.
2 Bảo mật thực tế: Thông báo chung "Thông tin không chính xác" giúp ngăn hacker biết được tên tài khoản có tồn tại hay không.
bai4_homework.js 
// Hai biến cố định theo đề bài
const USERNAME_CORRECT = "admin";
const PASSWORD_CORRECT = "123456";

let u = prompt("Nhập username:");
let p = prompt("Nhập password:");

// Cấu trúc if...else với toán tử &&
if (u === USERNAME_CORRECT && p === PASSWORD_CORRECT) {
    alert("Đăng nhập thành công");
} else {
    alert("Thông tin không chính xác");
}
Bài tập 05

Máy Tính Giảm Giá (Discount Calculator)

amount > 500000 discount = 10% tienPhaiTra
📌
Yêu cầu đề bài: Nhập số tiền hóa đơn. Nếu số tiền > 500.000đ thì giảm giá 10%, ngược lại không giảm. Tính số tiền cuối cùng phải trả.
⚡ Khu vực trải nghiệm trực tiếp
Chính sách: Hóa đơn trên 500.000đ giảm ngay 10%
Hóa đơn mẫu:
Bấm nút "Tính Tiền" để xem chiết khấu.
🧠 Phân tích thuật toán & Code mẫu
1 Điều kiện: Phải là amount > 500000 (lớn hơn hẳn, nếu đúng bằng 500.000 thì không giảm).
2 Tiền thực trả: thực_trả = hóa_đơn - tiền_giảm.
bai5_homework.js 
let tongTien = parseFloat(prompt("Nhập số tiền hóa đơn:"));
let tienGiam = 0;

if (tongTien > 500000) {
    tienGiam = tongTien * 0.10; // Giảm 10%
} else {
    tienGiam = 0;            // Không giảm
}

let tienPhaiTra = tongTien - tienGiam;
console.log(`Thực trả: ${tienPhaiTra.toLocaleString("vi-VN")} VND`);
alert(`Số tiền cuối cùng phải trả là: ${tienPhaiTra.toLocaleString("vi-VN")} VND`);
Bài tập 06

Phân Loại Tam Giác (Kiểm Tra Tam Giác Đều)

BĐT Tam Giác a === b && b === c Hình học phẳng
📌
Yêu cầu đề bài: Nhập vào 3 cạnh của một tam giác. Kiểm tra xem đó có phải là tam giác đều không (3 cạnh bằng nhau).
⚡ Khu vực trải nghiệm trực tiếp
Bộ 3 cạnh test:
Bấm nút "Phân Loại Tam Giác" để xem kết quả.
🧠 Phân tích thuật toán & Code mẫu
1 Bất đẳng thức tam giác: Tổng 2 cạnh bất kỳ luôn > cạnh còn lại: (a+b>c) && (a+c>b) && (b+c>a) và các cạnh phải > 0.
2 Tam giác đều: 3 cạnh bằng nhau: a === b && b === c.
bai6_homework.js 
let a = parseFloat(prompt("Nhập cạnh a:"));
let b = parseFloat(prompt("Nhập cạnh b:"));
let c = parseFloat(prompt("Nhập cạnh c:"));

// Kiểm tra điều kiện tồn tại tam giác
let isValid = (a > 0 && b > 0 && c > 0) &&
              (a + b > c) && (a + c > b) && (b + c > a);

if (!isValid) {
    alert("Ba cạnh này không tạo thành tam giác!");
} else if (a === b && b === c) {
    alert("Đây là TAM GIÁC ĐỀU (3 cạnh bằng nhau)");
} else {
    alert("Đây KHÔNG PHẢI là tam giác đều.");
}
