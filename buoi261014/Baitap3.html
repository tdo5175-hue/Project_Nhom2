Tính Chỉ Số BMI Cơ Bản & Đánh Giá Thể Trạng

📌
Yêu cầu đề bài: Nhập chiều cao (m) và cân nặng (kg). Tính BMI = cân nặng / (chiều cao * chiều cao) và in ra kết quả.
⚡ Khu vực thao tác trực tiếp
Đơn vị mét (ví dụ 1m70 nhập 1.70)
Đơn vị kilôgam (kg)
Mẫu thể trạng:
BMI: 22.49
• Đánh giá thể trạng: Bình thường (Thân hình cân đối)
• Công thức tính toán: 65 kg / (1.70 m)² = 22.49
• Khuyến nghị: Hãy duy trì chế độ dinh dưỡng và sinh hoạt này!
>_ KẾT QUẢ THỰC THI (CONSOLE LOGGER)
Chiều cao: 1.7m | Cân nặng: 65kg => BMI: 22.49 (Bình thường)
🧠 Tư duy logic & Mã nguồn chi tiết
Baitap3.js 
// =========================================================
// BÀI 3: TÍNH CHỈ SỐ BMI CƠ BẢN
// =========================================================

// Bước 1: Nhập chiều cao (m) và cân nặng (kg) qua prompt
let inputHeight = prompt("Nhập chiều cao của bạn theo MÉT (Ví dụ: 1.70):");
let inputWeight = prompt("Nhập cân nặng của bạn theo KG (Ví dụ: 65):");

// Bước 2: Kiểm tra hủy bỏ
if (inputHeight === null || inputWeight === null) {
    console.log("Người dùng đã hủy thao tác tính BMI.");
} else {
    // Bước 3: Ép kiểu sang số thực bằng parseFloat
    let h = parseFloat(inputHeight);
    let w = parseFloat(inputWeight);

    // Hỗ trợ tự động nếu nhập nhầm cm thay vì mét (ví dụ 170cm)
    if (h > 30) h = h / 100;

    // Bước 4: Kiểm tra hợp lệ (phải là số dương lớn hơn 0)
    if (isNaN(h) || h <= 0 || isNaN(w) || w <= 0) {
        console.error("Lỗi: Chiều cao và cân nặng phải là số dương lớn hơn 0!");
        alert("Vui lòng nhập chiều cao và cân nặng hợp lệ!");
    } else {
        // Bước 5: Tính chỉ số BMI theo công thức đề bài
        // BMI = cân nặng / (chiều cao * chiều cao)
        let bmi = w / (h * h);

        // Bước 6: Phân loại thể trạng theo tiêu chuẩn y tế (WHO)
        let phanLoai = "";
        if (bmi < 18.5) {
            phanLoai = "Gầy (Thiếu cân)";
        } else if (bmi < 24.9) {
            phanLoai = "Bình thường (Cân đối)";
        } else if (bmi < 29.9) {
            phanLoai = "Thừa cân (Tiền béo phì)";
        } else {
            phanLoai = "Béo phì";
        }

        // Bước 7: Xuất kết quả ra console và alert
        console.log(`BMI: ${bmi.toFixed(2)} - Phân loại: ${phanLoai}`);
        alert(`Chỉ số BMI của bạn là: ${bmi.toFixed(2)}\nTình trạng thể trạng: ${phanLoai}`);
    }
}
