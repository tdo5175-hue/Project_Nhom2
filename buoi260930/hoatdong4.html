Tối Ưu Hóa Mã CSS Do AI Sinh Ra

Áp dụng 3 kỹ thuật: Loại bỏ thuộc tính mặc định • Gộp Selectors • Sử dụng Shorthand Properties.

❌ Trước Khi Tối Ưu (Rườm rà & Thừa)

/* Mã AI sinh ra chưa tối ưu (38 dòng) */
.container {
    display: block;             /* Mặc định của div */
    width: 100%;                /* Block mặc định 100% */
    position: static;           /* Giá trị mặc định */
    margin-top: 20px;
    margin-bottom: 20px;
    margin-left: 0;
    margin-right: 0;
    padding-top: 15px;
    padding-bottom: 15px;
    padding-left: 20px;
    padding-right: 20px;
}

.card-primary {
    background-color: #f8fafc;
    border-width: 1px;
    border-style: solid;
    border-color: #e2e8f0;
    border-radius: 10px;
    padding-top: 20px;
    padding-bottom: 20px;
    padding-left: 20px;
    padding-right: 20px;
}

.card-secondary {
    background-color: #f8fafc;  /* Trùng lặp */
    border-width: 1px;          /* Trùng lặp */
    border-style: solid;        /* Trùng lặp */
    border-color: #e2e8f0;      /* Trùng lặp */
    border-radius: 10px;        /* Trùng lặp */
    padding-top: 20px;          /* Trùng lặp */
    padding-bottom: 20px;
    padding-left: 20px;
    padding-right: 20px;
}

.flex-box {
    display: flex;
    flex-direction: row;        /* Mặc định là row */
    flex-wrap: nowrap;          /* Mặc định là nowrap */
    justify-content: flex-start;/* Mặc định flex-start */
}

✅ Sau Khi Tối Ưu (Tinh Gọn & Chuẩn DRY)

/* Mã tối ưu hóa chuyên nghiệp (16 dòng) */
.container {
    /* Shorthand margin & padding, bỏ block/static */
    margin: var(--spacing-unit) 0;
    padding: 15px var(--spacing-unit);
}

/* Gộp chung selector có thuộc tính giống nhau */
.card-primary,
.card-secondary {
    background: var(--color-bg-card);
    border: 1px solid var(--color-border); /* Shorthand */
    border-radius: var(--radius-md);
    padding: var(--spacing-unit);          /* Shorthand */
    color: var(--color-text-dark);
}

.card-primary {
    border-left: 4px solid var(--color-primary);
}

.card-secondary {
    border-left: 4px solid #8b5cf6;
}

/* Loại bỏ hoàn toàn các thuộc tính Flex mặc định */
.flex-box {
    display: flex;
    gap: var(--spacing-unit);
}

⚡ Card Primary

Được xây dựng từ selector gộp .card-primary, .card-secondary kết hợp shorthand border và padding giúp tiết kiệm 60% dòng mã.

🎯 Card Secondary

Chia sẻ chung toàn bộ thuộc tính nền, viền và bo góc từ selector gộp, chỉ ghi đè duy nhất màu viền trái border-left.

📌 3 Nguyên Tắc Tối Ưu Hóa CSS Trọng Tâm

  • 1. Loại Bỏ Thuộc Tính Mặc Định

    Tránh khai báo display: block cho thẻ div/p, position: static, hoặc flex-direction: row vì trình duyệt đã mặc định gán sẵn.

  • 2. Gộp Class Trùng Thuộc Tính

    Sử dụng .class-a, .class-b { ... } để tập trung các thuộc tính chung, chỉ viết riêng rẽ các thuộc tính biến thể (variant styles).

  • 3. Sử Dụng Shorthand Properties

    Thay vì viết 4 dòng margin-top/right/bottom/left hay 3 dòng border-*, gộp thành 1 dòng duy nhất giúp mã ngắn gọn và tải nhanh hơn.
